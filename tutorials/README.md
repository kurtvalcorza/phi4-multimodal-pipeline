## Conformance notes

- **Standalone (ST1–ST8):** the default path performs no clone, no repository install and no repository import; the three package modules (`pipeline.py`, `metrics.py`, `samples.py`) are carried verbatim in dependency order with their SHA-256 tags, the identity constants live in the carried module only, and the inline manifest and pins are asserted against the repository by the parity tests.
- **Remote code (MOD6/MOD9/MOD10), stated rather than hidden:** the model cell states that this checkpoint ships its own model code and that `verify_snapshot` re-hashes the five Python files before `from_pretrained` imports them with `trust_remote_code=True` behind the explicit `allow_remote_code=True` opt-in; `verify_snapshot` refuses a manifest that does not pin those files.
- **Model acquisition (MOD1–MOD8):** `stage_missing_files` fetches only absent manifest entries from the Hub at the immutable revision `93f923e1a7727d1c4f446756212d9d3e8fcc5d81` (never `main`); `verify_snapshot` re-hashes all 26 files and raises on the first mismatch; there is no fallback to a different download. The 4-bit load (`quantization='nf4'`) needs CUDA.
- **Sample data (DAT1–DAT9):** the VizWiz-Captions slice is read from one pinned parquet shard over HTTPS range requests — shard size and SHA-256 checked before any byte, decoded text columns' SHA-256 and every photograph's size and SHA-256 checked after — and split by image with `check_split_disjoint`; four refusal probes are executed so the failure messages are visible.
- **Evaluation (EVAL2/EVAL6/EVAL9/EVAL10/EVAL21):** the headline metric is CIDEr-D, read beside BLEU-4, ROUGE-L and the unigram-F1 plumbing check; the constant-caption and colour-neighbour baselines are fitted on the training split only and scored on the same 70 held-out photographs as the frozen and adapted models; the cells assert frozen > constant caption and adapted > frozen and > both baselines on CIDEr-D. The three capability outputs keep their `not-measurable` verdict (no references).
- **Score semantics (UNC1/UNC2):** generated text carries no likelihood or calibrated confidence; the one seeded draw is labelled as having no dispersion estimate; the frozen numbers are those of the quantised model.
- **Ceilings (VAL6):** `MAX_IMAGES` 4, `MAX_AUDIOS` 4, `MAX_NEW_TOKENS` 2048, `MAX_TEMPERATURE` 2.0, `CAPTION_MAX_SIDE` 448, `CAPTION_MAX_NEW_TOKENS` 40, `MIN_RECORDS` 8, `MAX_RECORDS` 5000 are printed before the model runs, and a too-many-images probe is rejected on record.
- **Artifact (OUT8, VER2, VER4):** `save_artifact` writes safetensors plus a manifest (format, base identity and shard digest, remote-code files, quantization, licence, tensor set, file digest, training history); the adapted model's captions are recorded, the model freed, and `from_artifact` reloads a fresh base and verifies the artifact before deserialising; the cell asserts identical captions on eight held-out photographs.
- **BYOD (DAT10–DAT19):** `USE_BYOD` defaults to `False` so the sample path never opens an upload dialog; when enabled, one zip with `records.jsonl` flows through the same validation, image-disjoint split, baselines, frozen evaluation, fine-tuning, evaluation and export cells.
- `eager` attention is the portable default; `flash_attention_2` is an explicit opt-in that the tutorial does not use.
- `tools/validate_release_assets.py` performs source validation only. It does not satisfy the clean-runtime execution requirement — see `../docs/release-verification.md`.
